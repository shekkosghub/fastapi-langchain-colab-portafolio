Sobre el libro
--------------

En este ebook aprenderás paso a paso a construir APIs funcionales para tu portafolio:

- Chatbot con memoria por sesión.
- Sistema RAG para preguntas sobre documentos.
- Resumidor de texto extenso.
- Generador de consultas SQL con lenguaje natural.
- Agente con herramientas externas y llamadas a APIs.
